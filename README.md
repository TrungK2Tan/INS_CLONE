# 📸 Instagram Clone

Dự án **Instagram Clone** mô phỏng các tính năng chính của Instagram, được xây dựng bằng **PHP** và sử dụng **XAMPP** làm môi trường phát triển. Hệ thống cho phép người dùng đăng ký, đăng nhập, chia sẻ hình ảnh, theo dõi người dùng khác và thích hoặc bình luận về các bài đăng.

## 🌟 Tính Năng

### Người Dùng:
- 📝 **Đăng ký/Đăng nhập**: Tạo tài khoản mới hoặc đăng nhập vào tài khoản đã có.
- 📷 **Chia sẻ bài đăng**: Đăng tải hình ảnh kèm mô tả.
- ❤️ **Thích và bình luận**: Thích hoặc bình luận về các bài đăng của người khác.
- 🔍 **Theo dõi**: Theo dõi và hủy theo dõi người dùng khác.
- 👤 **Hồ sơ cá nhân**: Quản lý thông tin cá nhân và xem lại các bài đăng đã chia sẻ.

## 🛠️ Công Nghệ Sử Dụng

- **Ngôn ngữ**: PHP, HTML, CSS, JavaScript
- **Cơ sở dữ liệu**: MySQL (trong XAMPP)
- **Quản lý phiên bản**: Git
- **Thư viện/Framework**: jQuery, Bootstrap (tùy chọn)

## 🚀 Hướng Dẫn Cài Đặt

### Yêu Cầu Hệ Thống:
- **XAMPP** (hoặc bất kỳ server PHP nào) với PHP và MySQL đã được cài đặt.
- **Trình duyệt web** (Google Chrome, Firefox,...).
- **Git** (để sao chép repository từ GitHub).
